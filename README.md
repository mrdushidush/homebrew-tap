# mrdushidush/tap

Homebrew formulae for [claudette](https://github.com/mrdushidush/claudette), the air-gapped coding agent in one Rust binary.

```sh
brew install mrdushidush/tap/claudette
```

The formula installs the prebuilt release binary for macOS (Apple silicon and Intel) and Linux (x86_64 and arm64); the checksums are the ones published with each release.
